# SaveSnapshot

Minecraft 26.2（Fabric）单人世界**存档快照** mod：一键保存当前内存中的世界状态，随时读档重来。

> 保存的是**快照**，不是整个世界：所有维度当前已加载的区块（方块、方块实体、实体）+ 玩家状态 + 维度时间天气。

## 功能

- **新建存档**：保存当前世界状态（手动命名，非法字符/重名自动校验）
- **覆盖存档**：选中已有存档后，"新建存档"按钮变为"覆盖存档"，用当前状态覆盖（带确认）
- **读取存档**：确认后自动退出世界、写回存档数据并自动重进
  - 回滚：位置、背包、装备、末影箱、血量、饥饿、经验、药水效果、世界时间、天气、已加载区块内的方块与实体
  - **不回滚**：成就、配方书、统计数据；快照范围外的区块保持现状
- **重命名 / 删除**：带确认弹窗
- **自动存档**：默认每 10 分钟一张，保留最近 10 张自动存档（轮转），均可在界面中调整
- 存档存放在世界目录 `<世界>/snapshots/<名称>/` 下，原版 NBT 格式

## 使用

- 游戏内按 **F9** 打开存档界面
- 或通过 **Mod Menu** → SaveSnapshot → 配置按钮打开
- 调试命令：`/savesnapshot create <名称>`、`/savesnapshot list`

## 依赖

| 依赖 | 版本 |
|---|---|
| Minecraft | 26.2 |
| Fabric Loader | ≥ 0.19.3 |
| Fabric API | 0.158.0+26.2 |
| Mod Menu | ≥ 20.0.0 |

仅单人（整合端）使用；不需要安装在服务器上。

## 构建

```bash
./gradlew build
# 产物：build/libs/savesnapshot-<版本>.jar
```

需要 JDK 25。

## 已知限制

- 与 `tickrate` mod 不兼容：该 mod 的 mixin 在退出世界的渲染帧中空指针崩溃（原版退出世界流程同样会触发）
- 存档中含其他 mod 的方块/实体时，读取环境需装有相同 mod
- 捕捉在服务端主线程同步执行，已加载区块极多时可能短暂卡顿
